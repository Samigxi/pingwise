Algorithm Complexity

Operation Complexity Explanation
XOR Distance O(B) B = bit length (16)
Bucket Index O(1) Highest set bit
Find Closest K O(N·log N) Sort by distance
Iterative Lookup O(log N) Halves distance each hop

XOR Distance Properties

d(x, x) = 0 Identity

XOR of any value with itself is zero

d(x, y) = d(y, x) Symmetry

Distance is the same in both directions

d(x, z) ≤ d(x, y) + d(y, z) Triangle Inequality

Satisfies metric space requirement

∀(x, Δ), ∃! y : d(x, y) = Δ Unidirectionality

Unique node at every distance
